# Slim Media Folders privacy and local-data statement

Slim Media Folders is designed to run locally on the customer’s WordPress site. The plugin does not require an external account, telemetry service, remote media processing service, or license server for its documented folder, gallery, analytics, review, and ZIP features.

The plugin stores folder definitions, folder assignments, appearance preferences, role permissions, analytics cache data, and temporary ZIP metadata in the site’s WordPress database and uploads directory. ZIP files are temporary and are removed after their expiry window or by the user. The site administrator controls access to this information and is responsible for backups, retention, and privacy notices required by local law.

The plugin may create links to an administrator-configured help URL. Visiting that URL is subject to the linked site’s privacy policy. No file is sent to that URL by the plugin.
