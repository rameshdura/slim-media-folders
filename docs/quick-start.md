# Slim Media Folders for WordPress — Quick Start

Slim Media Folders uses virtual folders. Organizing an item never changes its physical file path or public URL.

## Install

1. In WordPress, open **Plugins > Add New > Upload Plugin**.
2. Select the Slim Media Folders release ZIP.
3. Install and activate the plugin.
4. Open **Media > Library**.

## Organize media

1. Select **New Folder** in the folder sidebar.
2. Enter a name and optionally choose a color.
3. Drag one or more media items onto the folder.
4. Select a folder to filter the Media Library.

Deleting a virtual folder returns its assigned items to Uncategorized. It does not delete physical media files.

## Organize posts, pages, and other content with Pro

1. Open **Slim Media Folders > Folders**.
2. Enable Posts or Pages for separate folder trees. These content folders, including folders for custom post types, are Pro features. Free organizes the Media Library.
3. Open the corresponding WordPress list screen and use its folder sidebar.

## Create a folder gallery

- In the block editor, insert **Media Folder Gallery** and choose a media folder.
- In Elementor, add the **Media Folder Gallery** widget and choose a folder.

Gallery contents update automatically when items are moved into or out of the selected virtual folder.

## Pro administration tools

- **Analytics:** Review file counts and local storage usage (Pro).
- **Unused files:** Review files for which the plugin could not detect a WordPress reference (Pro). Always inspect a file before moving it to Trash.
- **Settings:** Configure role permissions and white-label options (Pro).
- **ZIP export:** Create a temporary authenticated archive containing up to 50 files from one folder (Pro).

## Support

Product information: https://slim-media-folders-site.vercel.app/

Support: https://slim-media-folders-site.vercel.app/#faq

Gallery settings in Gutenberg and Elementor include columns, image size, lightbox, attachment captions, grid or masonry layout, and images per page. Set images per page to 0 to show the whole folder. Pagination links use a folder-specific URL parameter.

Shortcode galleries and the shortcode builder are available in the optional Pro add-on. Free users can build galleries with the Gutenberg block or Elementor widget.
